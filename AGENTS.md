# AGENTS.md

Rx extensions over `System.IO.Ports.SerialPort` (reactive reads/writes). Two projects: `RxSerialPort` (library) and `RxSerialPort.Tests`. Solution: `RxSerialPort.slnx`. Active branch is `develop`; `main` is release-only.

## Build & test

- `dotnet build` / `dotnet test` at the repo root — tests run across all TFMs (xunit.v3 + Microsoft.Testing.Platform; the test project is an `Exe`).
- To run a single framework, use `--project`: `dotnet test --project RxSerialPort.Tests/RxSerialPort.Tests.csproj -f net8.0`. This SDK (10.0.110) rejects passing the csproj positionally — `--project` is required.
- The library multi-targets `netstandard2.0;net8.0;net9.0;net10.0`; keep library code netstandard2.0-compatible.
- Formatting: `dotnet format`. The `.editorconfig` enforces tabs, CRLF, BOM, and *no* trailing newline — match it or you'll generate noisy diffs. Avoid `var` (style rules require explicit types); member access is qualified with `this.`.

## Namespace is deliberate

All public API lives in namespace `System.IO.Ports` (the `RootNamespace` of both projects) so extensions appear on `SerialPort`. Do not "fix" this to `RxSerialPort`.

## TEST_WITH_REAL_PORTS

Integration tests needing real hardware are wrapped in `#if TEST_WITH_REAL_PORTS` (Connect/Observer/Extensions.Watch tests). They are off by default and use `SerialPort.GetPortNames()[0]`, so they need a pair of linked virtual COM ports (e.g. NetBurner VirtualComPort). Enable locally with `-p:TEST_WITH_REAL_PORTS=true`. CI runs with them off.

## Architecture

- `RxSerialPortEvent<TData>` / `RxSerialPortEventType` is the event model flowing through the observables.
- `RxSerialPort.Connect(...)` builds read streams: static overloads manage the port internally (`Observable.Using`) and dispose it on unsubscribe; the `SerialPort.Connect()` extension leaves the port externally managed. Both rely on `serialPort.Events()` generated by `ReactiveMarbles.ObservableEvents.SourceGenerator`.
- `RxSerialPort_Extensions` (partial class): `AndRead*` reads per event (loops while `BytesToRead > 0`), `Watch*` filters event streams, `WriteTo`/`WriteLineTo` bridge an `IObservable<T>` to writes.
- `RxSerialPort_Observer.Create` / `AsObserver` wrap a `SerialPort` into an `IObserver<TData>` for writes.

## Versioning

Version comes from Nerdbank.GitVersioning (`version.json`, semVer2, derived from git state) — don't hand-edit versions. CI (`.github/workflows/ci-build.yml`) builds/packs/tests on push to `develop` and PRs to `main`/`develop`; a merged PR into `main` triggers the NuGet publish + GitHub release.
